# Evidence

Evidence is part of the product, not an afterthought. Each phase report must contain Goal, Implementation, Verification commands, Results, relevant output, files changed and Known Limitations.

Required reports:

- `phase-0/report.md`
- `phase-1/runtime-report.md`
- `phase-1/persistence-report.md`
- `phase-2/prompt-context-report.md`
- `phase-2/compaction-report.md`
- `phase-3/replay-report.md`
- `phase-3/inspector-report.md`
- `phase-4/report.md`
- `final-report.md`

Reports must show actual test/demo output; “implemented successfully” alone is not evidence. Keep secrets and API keys out of reports.
