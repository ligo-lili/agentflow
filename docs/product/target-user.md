# Target User

The primary user is a Python or AI engineer building an Agent with an API, an SDK, LangGraph, PydanticAI or a custom runtime.

Their recurring question is not “what answer did the model return?” but “what did the model see, what changed, and why did the Agent take this step?”

## Core journey

1. Run a deterministic Agent task.
2. Open the resulting session.
3. Inspect timeline, prompt sections, context components and token growth.
4. Identify a low-value or oversized component.
5. Compare two compaction strategies on the same fixture.
6. Use metrics and evidence to justify the change.
